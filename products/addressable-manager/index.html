Overview

A wrapper that makes Addressables easier

Addressables is a powerful package from Unity, but it can be inefficient to use. Addressable Manager is a wrapper to help you use it more easily. It is an essential tool for Gtion's own work, sold at the lowest paid price so as many people as possible can use it.

Using Addressables can be as simple as this:

AssetReference<GameObject> reference;

var asset = await reference.LoadAssetAsync();

That looks normal, but you are not limited to using it just once. Doing this again and again is fine, without errors:

asset = await reference.LoadAssetAsync();
asset = await reference.LoadAssetAsync();
asset = await reference.LoadAssetAsync();

Simple loading

Simplifies asset loading and addressable scene loading.

On-demand download

Simplifies on-demand download of addressable content.

MonoBehaviour references

Allows addressables to reference MonoBehaviour.

Key features

  • Simplify asset loading
  • Simplify addressable scene loading
  • Simplify on-demand download
  • Allows addressables to reference MonoBehaviour
  • Avoid loading error shader for specific platform

Requires: Unity 2022.3 or newer and the Addressables package. Works with Built-in, URP and HDRP.
