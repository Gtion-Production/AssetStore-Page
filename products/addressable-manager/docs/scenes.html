Scenes and Preloading

Load, unload and preload scenes with AssetReferenceScene.

Load and unload

AssetReferenceScene is made for scenes. You can load and unload with it.

AssetReferenceScene sceneRef;

if (isUnloadScene)
{
    await sceneRef.UnloadSceneAsync();
}
else
{
    await sceneRef.LoadSceneAsync(LoadSceneMode.Additive);
}

Preload a scene

You may want to load a scene in advance. Pass activateOnLoad: false to preload it, then activate it when you are ready.

private async void PreloadScene() //wrap it in a C# async method so it does not block the logic
{
    //use `activateOnLoad: false` to preload
    await sceneRef.LoadSceneAsync(LoadSceneMode.Additive, activateOnLoad: false);
}

//then at another time, when you are ready to load
await sceneRef.ActivateAsync();
Warning: preloading blocks all other async methods. This is a Unity bug and happens with a normal scene load too, not only with Addressables.
