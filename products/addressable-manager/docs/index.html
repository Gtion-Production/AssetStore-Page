Addressable Manager Documentation

A wrapper package that makes Addressables easier to use, handle and manage.

Addressable Manager by Gtion is a wrapper package that makes it easier to use, handle and manage Addressables. Loading the same reference again and again just works, and scenes, downloads and editor tooling get simpler APIs.

AssetReference<GameObject> reference;
var prefab = await reference.LoadAssetAsync();
