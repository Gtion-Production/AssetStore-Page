Why This Package

What Addressable Manager is, and why you need it.

Addressable Manager is a wrapper package that makes it easier to use, handle and manage Addressables. If you have worked with Addressables, you may have handled loading like this:

var prefab = await reference.LoadAssetAsync().Task; //original implementation

The problem is that the second time you load the same reference, it gives an error. Even the example in the official documentation loads this way. It is inconvenient to handle this again and again, so this package is the solution for using and managing Addressables.

See the official Addressables documentation.
