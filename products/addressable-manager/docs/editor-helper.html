Editor Helper

Helpers for editor tools that work with Addressables.

If you make editor tools that involve Addressables, AddressableEditorHelper.cs helps. It handles three things:

//to get all labels for a certain asset
AddressableEditorHelper.GetReferenceLabel(IKeyevaluator);

//insert a unity object into an addressable bundle
AddressableEditorHelper.SetAsAddressable(Object unityObj, bool askQuestion = true, AddressableAssetGroup bundle = null);

//convert a unity object to an AssetReference (it also inserts it into the addressable bundle)
AddressableEditorHelper.ConvertToAssetReference(Object unityObj, bool askQuestion = true, AddressableAssetGroup bundle = null);
