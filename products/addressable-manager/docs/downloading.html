Downloading Bundles

Download a bundle before you need it.

Splitting the build into several bundles is the heart of Addressables. By default, await reference.LoadAssetAsync(); loads the addressable automatically. If a bundle is big, it takes longer to load, and loading a big bundle during play is not wise. AddressableManager.cs is the class that mainly handles downloading.

//Download all assets
AddressableManager.DownloadDepedenciesAsync(IEnumerable<IKeyEvaluator> keys, Action<DownloadStatus> callback);
IKeyEvaluator can be an AssetReference or a Label.

The package also includes a MonoBehaviour wrapper, InAppDownloadHandler, for easier downloads.
