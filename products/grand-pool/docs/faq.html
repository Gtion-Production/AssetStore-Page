FAQ

Common questions.

Is it mobile friendly?

Yes. It is used in every Gtion project.

No setup is needed, how?

You can set up how much to prewarm. If you do not, the default configuration is used. See Warming Up.

How about a leak?

Clean up is handled automatically.

Can it work on UI?

Yes. It can pool anything that needs optimization.

If I use Destroy instead of Release, is it a memory leak?

No, but it loses the purpose of reusing the object. Call Release() instead.

Where do I report a bug or ask for support?

Join the Gtion community.
