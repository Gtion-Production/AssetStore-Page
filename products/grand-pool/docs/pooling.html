Pooling

Pool GameObjects, native components and custom classes.

GetPool() takes a position, a rotation and a parent: GetPool(Position, Quaternion, Parent). It works the same on a GameObject, a native component or a custom class. Call Release() on the instance to return it.

[SerializeField]
GameObject style1;
[SerializeField]
MeshRenderer style2;
[SerializeField]
CustomClass style3;

public async void StyleGO()
{
    var pos = GetSpawnPos();
    GameObject instance = style1.GetPool(pos, Quaternion.identity, null);

    await Task.Delay(3000);
    instance.Release();
}

public async void StyleComponent()
{
    var pos = GetSpawnPos();
    var instance = style2.GetPool(pos, Quaternion.identity, null);

    await Task.Delay(3000);
    instance.Release();
}

public async void StyleCustom()
{
    var pos = GetSpawnPos();
    AutoDestroyComponent instance = style3.GetPool(pos, Quaternion.identity, null);

    await Task.Delay(3000);
    instance.Release();
}

Custom classes

To enable pooling for a custom class, the class has to implement the GrandPooling.IObjectPool<T> interface.

public class CustomClass : MonoBehaviour, IObjectPool<CustomClass>
{
}
Several objects of the same type are supported. As long as you give a different prefab, the pool is handled automatically.
