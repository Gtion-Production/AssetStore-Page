Clean Up

Free memory and destroy all items of a pool.

To free memory and destroy all pool items, call DestroyPoolManager() on the prefab or component you pooled.

[SerializeField]
GameObject style1;
[SerializeField]
MeshRenderer style2;
[SerializeField]
CustomClass style3;

//destroy pool here!
style1.DestroyPoolManager();
style2.DestroyPoolManager();
style3.DestroyPoolManager();

private void CleanUp()
{
   cube.DestroyPoolManager();
}
Grand Pool also cleans up automatically, so leaks are handled for you.
