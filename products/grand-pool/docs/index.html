Grand Pool Documentation

The easiest pooling system for Unity: call GetPool() and you are done.

Grand Pool by Gtion is a pooling system for Unity. A pool keeps a collection of inactive objects ready to be reused. Instead of creating and destroying objects (such as game objects or prefabs) again and again, which is expensive and leads to memory fragmentation, you take an object from the pool and give it back when you are done.

It pools GameObjects, Unity native components (Mesh, ParticleSystem, SpriteRenderer and more) and custom MonoBehaviour classes. No setup is needed: reference your prefab and call GetPool().
