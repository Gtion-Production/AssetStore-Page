Getting Started

Spawn an object from a pool and give it back.

Keep a reference to your prefab, call GetPool() to get an instance, and call Release() to return it to the pool.

[SerializeField]
GameObject cube; //you need reference of your prefab

private async void SpawnCube()
{
    //this is how you instantiate from pool
    GameObject instance = cube.GetPool(new Vector3(0,0,0), Quaternion.identity);

    await Task.Delay(3000);
    //this is how you return your instance to pool
    instance.Release();
}
You do not need to set anything up in the editor. You can call GetPool() without any setup.
