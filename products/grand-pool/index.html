Overview

The easiest pooling system for Unity

No hassle setup: install it and use it right in your code. A pooling system is a performance optimization technique for managing the creation, reuse and destruction of objects. Instead of frequently creating and destroying objects, which is expensive and leads to memory fragmentation, a pool keeps a collection of inactive objects ready to be reused.

Prefab.GetPool()

Setup is not essential. Just call Prefab.GetPool(), that's it!

Pool anything

Pools GameObjects, Unity native components (Mesh, ParticleSystem, SpriteRenderer and more) and custom classes derived from MonoBehaviour. It works on UI too.

Prewarm

Prewarm a pool, lazy or non-lazy. You can define how much to prewarm, or use the default configuration.

Limits and cleanup

Limit the size of a pool, clean it up, or let Auto Clean handle leaks for you.

Key features

  • Pooling GameObject
  • Pooling Unity native component (Mesh, ParticleSystem, SpriteRenderer, etc.)
  • Pooling custom class (derived MonoBehaviour class)
  • Prewarm pooling (lazy and non-lazy)
  • Pool limitation
  • Clean up pool
  • Auto clean pool

Q&A

  • Is it mobile friendly? Yes. It is used in every Gtion project.
  • No setup needed, how? You can define how much to prewarm. If you do not, the default configuration is used.
  • What about leaks? Clean up is handled automatically.
  • Can it work on UI? Yes. It can pool anything that needs optimization.

Requires: Unity 2022.3 or newer. Works with Built-in, URP and HDRP.
