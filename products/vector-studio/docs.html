Introduction

Vector Studio is a set of tools for working with vector graphics in Unity: an editor for authoring artwork, a runtime renderer for drawing it in your game, UI Toolkit integration and a library of icons.

Installation

  1. Open the Unity Asset Store page for Vector Studio (link available at release) and add it to your assets.
  2. In Unity, open Window › Package Manager, choose My Assets, find Vector Studio and click Import.
  3. Wait for the import and script compilation to finish.

Supported Unity versions and render pipelines will be listed here at release.

Vector Graphics Editor

The editor is where you create and edit vector artwork inside Unity.

  • Draw shapes and paths and adjust their fills and strokes.
  • Save your artwork as an asset in your project.
  • Edit existing artwork at any time. Nothing is baked to pixels.

Runtime Renderer

The runtime renderer draws vector artwork in your game. Because the artwork is vector data, it stays sharp at any resolution and scale.

  1. Add the vector artwork asset to a scene.
  2. Adjust its size, color and sorting as needed.
  3. Press Play. The renderer draws it at the current screen resolution.

UI Toolkit

Use vector artwork in UI Toolkit interfaces so buttons, panels and backgrounds stay crisp on every display.

  • Assign vector artwork as an element background in UI Builder or in UXML/USS.
  • Scale elements freely without exporting extra textures.

Icons

Vector Studio includes a library of icons that scale and recolor without additional texture assets. Use them in the editor, at runtime or in UI Toolkit.
