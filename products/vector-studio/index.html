Vector Studio

Vector Graphics Editor, Runtime Renderer, UI Toolkit & Icons for Unity.

By Gtion Team · Tools

Go to Asset Store · Coming Soon Documentation
Overview

One toolset for vector graphics in Unity

Vector Studio lets you draw, import and render resolution-independent vector graphics without leaving Unity. Author artwork in the built-in editor, then draw it crisply at any size at runtime and in UI Toolkit.

Vector Graphics Editor

Create and edit shapes, paths and fills directly in the Unity Editor and save them as reusable assets.

Runtime Renderer

Render vector artwork in your game at any resolution, with sharp edges at every scale.

UI Toolkit

Use vector graphics as UI Toolkit elements and backgrounds so interfaces stay sharp on every screen.

Icons

Ready-to-use vector icons that scale and recolor without extra texture assets.
