Overview

One toolset for vector graphics in Unity

Vectoria lets you draw icons, HUD graphics and illustrations in a built-in vector editor, save them as .vpaint documents, and render them crisply at any size in UI Toolkit or uGUI. Requires Unity 6000.3 or newer.

Illustrator

Draw vector art with a full set of shape, pen and type tools. Import and export SVG, export PNG and JPEG, and save as .vpaint documents.

uGUI & UI Toolkit

Supports both Unity UI systems, each with its own optimized renderer: VectoriaImage for uGUI and VectoriaImageElement for UI Toolkit.

Runtime Renderer

Automatic GPU shader drawing with fast mesh and raster fallbacks, plus single-mesh batching for many icons.

Highlights

  • uGUI and UI Toolkit. Works with both UI systems, so you can use the same artwork in either.
  • Pre-baked for runtime. On import, a .vpaint is precompiled into shader data and small raster tiles stored in the asset, so artwork is ready on the first frame with no runtime setup cost. The baked data is far smaller than a raster export.
  • Shader resolver. Each icon is a single quad with nothing tessellated, and the GPU works out the shape per pixel. Edges stay crisp at any size.
  • Low draw calls. Icons batch together, so thousands of them draw in a handful of calls instead of one per icon.
  • Raster LOD. Small icons switch to a pre-baked raster tile, and everything else stays on the vector shader. Tiles are baked at import and share one atlas, so they batch with the rest.
  • Agent-friendly. The included skill lets a coding agent such as Claude Code create, draw, render and check documents.

Requires: Unity 6000.3+, URP for the shader resolver, and the Vector_Painter_Enabled scripting define. Start with the Quick Start.
