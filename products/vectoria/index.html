Overview

One toolset for vector graphics in Unity

Vectoria lets you draw icons, HUD graphics and illustrations in a built-in vector editor, save them as .vpaint documents, and render them crisply at any size in UI Toolkit or uGUI. Requires Unity 6000.0 or newer.

Vector Editor

Draw shapes and paths, import SVG, and save artwork as .vpaint documents. Open it from Tools › Vectoria.

Runtime Renderer

Automatic GPU shader drawing with fast mesh and raster fallbacks, plus single-mesh batching for many icons.

UI Toolkit & uGUI

Use VectorImageElement in UI Toolkit or VectorImage in uGUI so interfaces stay sharp on every screen.

Animation & AI Skill

Animate artwork at runtime with records (experimental), and let a coding agent draw and inspect documents through the included skill.
