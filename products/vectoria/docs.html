Introduction

Vectoria – Illustrator & Renderer by Gtion – is a vector art editor and runtime renderer for Unity. Draw icons, HUD graphics and illustrations, save them as .vpaint documents, and show them in UI Toolkit or uGUI.

Installation

  1. Open the Unity Asset Store page for Vectoria (link available at release) and add it to your assets.
  2. In Unity, open Window › Package Manager, choose My Assets, find Vectoria and click Import.
  3. Wait for the import and script compilation to finish.

Requires Unity 6000.0 or newer, with Burst, Mathematics, Collections, uGUI and 2D Sprite. Add the scripting define Vector_Painter_Enabled in Project Settings › Player to enable the module; Vector_Painter_Experimental enables runtime records.

Vector Editor

Open the editor from Tools › Vectoria › Open Vectoria, or double-click a .vpaint file.

  • Draw shapes and paths and adjust their fills and strokes.
  • Import SVG and save your artwork as a .vpaint document.
  • Edit existing artwork at any time. Nothing is baked to pixels.

Runtime Renderer

The runtime renderer draws vector artwork in your game. Because the artwork is vector data, it stays sharp at any resolution and scale.

  • Resolvers: Automatic (GPU shader when possible), fast mesh, shader and raster fallback.
  • Single-mesh batching for many icons with VectorBatchGroup.
  • Runtime records for animating artwork (experimental).

UI Toolkit & uGUI

Use vector artwork in UI Toolkit with VectorImageElement, or in uGUI with VectorImage.

  1. Draw in the Vectoria window and save a .vpaint.
  2. Add a VectorImageElement in UI Builder, set Source to the .vpaint and give it a size.
var icon = root.Q<VectorImageElement>("heart");
icon.SetParam("Pop", 1f, interpolate: true, duration: 0.2f);

AI Skill

Vectoria ships with a skill that lets a coding agent (such as Claude Code) draw, edit and preview documents through the Unity CLI vp_* commands. Copy the vectoria/ skill folder into your agent's skills folder and follow the included README.
