AI Skill

Draw and inspect vector art through the Unity CLI.

Vectoria ships with a skill that lets a coding agent (such as Claude Code) draw, edit and inspect .vpaint documents through the Unity CLI vp_* commands. Copy the vectoria/ skill folder into your agent's skills folder.

Commands

CommandUse
vp_new--path --width --height [--background] create a document
vp_apply--path --opsFile ops.json [--render out.png] [--dryRun] batch draw/edit; atomic, nothing is saved if one op fails
vp_describe--path list artboards, layers and shapes (id, type, bounds, fill, stroke, text)
vp_render--path [--out png] [--artboard n] [--scale|--maxSize] [--background ...] headless PNG of the artwork
vp_import_svg--svg file-or-markup --path out.vpaint
vp_export_svg--path [--out file.svg]
vp_openopen a document in the painter window

Workflow

  1. Write ops to a scratch file.
  2. vp_apply with --render to get a PNG.
  3. Look at the PNG, fix with vp_describe plus set/move ops, repeat.
{"ops":[
 {"op":"rect","x":0,"y":0,"w":128,"h":128,"r":24,"fill":"linear:#3a7bd5,#00d2ff","angle":90},
 {"op":"star","cx":64,"cy":64,"r":40,"points":5,"inner":0.45,"fill":"#ffffff"},
 {"op":"set","id":-1,"stroke":"#0a3a6a","sw":3,"opacity":0.95}
]}

Coordinates are document units, origin top-left, y down. Colors are #RRGGBB[AA]. Shape ops: rect ellipse circle polygon star line path text svg; edit ops: set move scale rotate duplicate group ungroup delete front back; structure ops: layer rename_layer delete_layer artboard add_artboard clear.

Do not run vp_apply on a document that is open and unsaved in the painter; the window's copy would overwrite it. Live effects, symbols, brushes, patterns, the boolean pathfinder and images are not covered by ops; use the editor, or vp_import_svg.
