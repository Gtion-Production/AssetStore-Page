Vectoria Image (Renderer)

Draw .vpaint artwork in UI Toolkit or uGUI.

Vectoria Image draws .vpaint artwork in your game. There is one component per UI system:

UI systemComponentPage
UI ToolkitVectoriaImageElementUI Toolkit
uGUIVectoriaImageuGUI

Both set Source/Document, Artboard, Scale Mode and a Resolver, and are sharp at any size.

In this section

  • Choosing a resolver: Automatic, Shader, MeshBatch, Painter2D
  • How drawing is optimized: the shader path, batching, Raster LOD and Runtime Raster
  • Runtime Raster: large artwork baked into a texture when it is worth it
  • Importer: artboard asset types, UI Vectoria, raster LOD
  • Settings: project defaults
  • UI Toolkit and uGUI
