Vectoria Image (Renderer)

Draw .vpaint artwork in UI Toolkit or uGUI, sharp at any size and cheap to run.

Vectoria Image is the runtime half of Vectoria. It takes a .vpaint document that you drew in the painter and draws it in your game. There is one component for each UI system, and both draw the same artwork with the same resolvers.

Pick your UI system

UI systemComponentPage
UI ToolkitVectoriaImageElementUI Toolkit
uGUI (Canvas)VectoriaImageuGUI

A resolver is the part that decides how the artwork is drawn (with a GPU shader, a batched mesh, or UI Toolkit's own vector painter, called Painter2D). You rarely need to change it, see Choosing a resolver.

Both let you choose the document, the artboard, how it scales into the box, a tint colour and a resolver. VectoriaImage is a normal uGUI Image, so it masks, raycasts and lays out like one.

Quick path

  1. Draw an icon in the painter and save it as a .vpaint in Assets.
  2. Add a Vectoria Image (uGUI) or a VectoriaImageElement (UI Toolkit) and pick the .vpaint and an artboard. Steps with pictures are on the uGUI and UI Toolkit pages, and a shorter version is in the Quick Start.
  3. If nothing draws, check the setup for the shader in the table below, or see Troubleshooting.

How artwork gets on screen

  1. Import. When Unity imports a .vpaint, the importer precompiles the artwork for the shader and bakes small raster tiles, so nothing has to be prepared at runtime. See Importer.
  2. Resolve. A resolver decides how the artwork is drawn: with a GPU shader, a batched mesh, or UI Toolkit's own vector painter. The default picks the shader whenever it can draw everything. See Choosing a resolver.
  3. Batch. In UI Toolkit, shader icons in the same group (a parent, or a VectorBatchGroup you define) share one mesh and one material, so they draw in one call. In uGUI, shader images on a Canvas share one material and batch together. Either way, hundreds of icons cost a few calls. See How rendering is optimized.
  4. Rasterize where it pays off. Small icons switch to a tile baked at import (Raster LOD). Large, costly artwork is baked once on the GPU (Runtime Raster). The shader draws while an icon animates.

Requirements

ForYou need
EverythingUnity 6000.0 or newer, and the scripting define Vector_Painter_Enabled in Project Settings › Player. Without the define nothing compiles, so if the components are missing, check it first.
Shader resolver in UI ToolkitURP, Unity 6000.3 or newer (custom materials in UI Toolkit), and the extra vertex channels on the PanelSettings. See Shader Setup.
Shader resolver in uGUIThe Canvas additional shader channels. See Canvas Setup.
MeshBatch and Painter2D resolversNothing extra.
