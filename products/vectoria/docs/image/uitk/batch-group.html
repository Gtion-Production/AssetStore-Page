VectorBatchGroup

One mesh and one draw call for a whole subtree.

VectorBatchGroup is a container: every shader-drawn VectoriaImageElement below it, at any depth, shares one mesh and one draw call. Without it the icons of each parent get their own mesh.

<Vectoria.VectorBatchGroup>
    <Vectoria.VectoriaImageElement source="..." />
    <ui:Label text="Inventory" />
</Vectoria.VectorBatchGroup>

Rules

  • The mesh sits where the group's first icon is, so inside the group all vector artwork is drawn below the group's text and other content. Lay the group out with backgrounds first and labels after.
  • Put the group on whatever moves, fades or is shown and hidden as a unit (a window, a card, a popover), so the mesh moves with it.
  • Groups can be nested; an icon belongs to the nearest one.
  • After reordering elements below the group (BringToFront, SendToBack, Insert) call group.Restack().
