Vectoria Documentation

Draw vector art in Unity, then show it sharp at any size, in UI Toolkit or uGUI.

Vectoria – Illustrator & Renderer by Gtion – is a vector art editor and runtime renderer. You draw icons, HUD graphics and illustrations in the Vectoria Painter window, save them as .vpaint documents, and display them with Vectoria Image. The artwork stays vector data, so it stays crisp at every resolution, aspect ratio and scale.

Two parts

  • Vectoria Painter is the editor. Draw shapes, paths, layers and artboards inside Unity, import or export SVG, and save the result as a .vpaint document.
    Open it from Tools › Vectoria › Open Vectoria Painter.
  • Vectoria Image is the renderer. It shows a .vpaint in your UI, using the resolver that suits each artwork.
    Use VectoriaImage for uGUI or VectoriaImageElement for UI Toolkit, and point it at your .vpaint. See Quick Start for the steps.
