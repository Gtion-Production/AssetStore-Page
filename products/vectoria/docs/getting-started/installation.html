Installation

Requirements and a quick check that Vectoria works.

Requirements

  • Unity 6000.3 or newer (minimum supported version).
  • Packages: Burst, Mathematics, Collections, uGUI and 2D Sprite (the editor needs 2D Sprite).
  • The GPU shader path in UI Toolkit needs URP. uGUI and the other paths do not have this limit.

Check it works

Open Tools › Vectoria › Open Vectoria Painter. The painter window opens. Then continue with the quick start.
