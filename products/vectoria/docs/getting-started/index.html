Getting Started

What Vectoria is and how this documentation is organised.

Vectoria – Illustrator & Renderer by Gtion – is a vector art editor and runtime renderer for Unity. You draw icons, HUD graphics and illustrations in the Vectoria Painter window, save them as .vpaint documents, and show them with Vectoria Image in UI Toolkit or uGUI. Because the artwork stays vector data, it is sharp at any resolution and scale.

What is in the package
