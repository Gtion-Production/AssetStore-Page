Core Concepts

The ideas the rest of the documentation builds on.

.vpaint document

A .vpaint file is one vector document: layers of shapes, and one or more artboards. It is JSON, so it diffs and merges in version control. Nothing is baked to pixels.

Artboard

An artboard is a rectangle of the document that you show as one image. A document can hold several artboards (variants of one icon, or a whole icon set in one file). Coordinates are document units, origin top-left, y grows down.

Resolver

A resolver decides how an artboard is drawn at runtime: Automatic (the default), Shader (GPU), MeshBatch (CPU mesh, batched) or, in UI Toolkit, Painter2D (full quality). See Choosing a resolver.
