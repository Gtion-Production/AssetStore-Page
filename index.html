NeuralNet Pro

Machine Learning

NeuralNet Pro is a machine learning package built on neural networks, supporting supervised and reinforcement learning. Train at runtime or in a build, on the main thread, multithreaded, with Jobs or GPU compute shaders.

Grand Pool

Runtime Tool

The easiest solution for a pooling system. Setup is not essential, just call Prefab.GetPool() and that is it! Instead of constantly creating and destroying objects, a pool keeps inactive objects ready to be reused, which saves performance and avoids memory fragmentation.

It pools GameObjects, native components (Mesh, ParticleSystem, SpriteRenderer and more) and custom MonoBehaviour classes. It also offers prewarming, pool limits and automatic cleanup, and it is mobile friendly.

Addressable Manager

Runtime Tool

A wrapper package that makes using Unity Addressables easier. Addressables is a powerful system, but it can be inefficient to use, so this package simplifies it. You can call LoadAssetAsync on the same reference again and again without errors.

It simplifies asset loading, scene loading and on-demand downloads, lets addressables reference MonoBehaviours, and avoids shader loading errors on specific platforms.
